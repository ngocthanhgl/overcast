# Solnim — brand guide

## Name
**Solnim** (sol = sun, nim = nimbus). Always written lowercase in the logo (`solnim`), capitalised in prose (Solnim).

## Logo
| File | Use |
|------|-----|
| `assets/logo/logo-lockup.svg` / `.png` | Mark + wordmark on light backgrounds |
| `assets/logo/logo-lockup-dark.svg` / `.png` | Mark + wordmark on dark backgrounds (white text) |
| `assets/logo/logo-mark.svg` / `.png` | Mark only, on light backgrounds |
| `assets/icon/icon-512.png`, `icon-1024.png` | App icon (full-bleed square, no rounded corners — the OS applies its own mask) |

Wordmark is Poppins Bold converted to outlines, so no font install is needed.

## Palette
| Role | Hex |
|------|-----|
| Sky gradient | `#8AD8FF` → `#3A7BFF` |
| Sun gradient | `#FFE46B` → `#FF9A3D` |
| Cloud (on sky) | `#FFFFFF` → `#D3E6FF` |
| Cloud (logo on white) | `#B6DCFF` → `#3F80FF` |
| Wordmark | `#14306B` (light) / `#FFFFFF` (dark) |

## Don'ts
- Don't recolour the sun or place the mark on busy photography without a solid or gradient backing.
- Don't stretch, rotate or add effects to the mark.
